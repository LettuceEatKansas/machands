# machands (Mac hands)

Rust desktop-control tool for AI agents (MCP server name `machands` on the Mac). Reads and drives native apps and a
Brave browser, with a safety gate and one-click Allow / Deny approvals for risky steps.

- Friends and new users on a Mac: [FRIENDS.md](FRIENDS.md) (one-command install for Claude Code)
- Mac install details and permissions: [docs/INSTALL-mac.md](docs/INSTALL-mac.md)
- Packaging scripts: [packaging/macos/README.md](packaging/macos/README.md)

The macOS bundle id `com.lettuceatkansas.winhands` is the app's identity for macOS permissions. It is kept as is.
